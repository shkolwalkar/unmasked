# Unmasked (DubHacks 2026)

Unmasked is a privacy-first extension that exposes greenwashing, verifies seller claims, and decodes fine print—helping shoppers spend ethically and buy with confidence.

## Features
**Verify Claims:** Extracts marketing promises and cross-references them against independent, third-party public evidence.  
**Instant Alerts:** Scans fine print, return windows, and hidden subscription traps to flag risks before checkout.  
**Smart History:** Analyzes past shopping and return behaviors to tailor risk warnings specifically to you.  
**Problem Registry:** A shared, peer-checked decentralized database where multi-agent consensus validates new seller findings.
